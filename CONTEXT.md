# Wiggler

Wiggler is a Windows utility that takes temporary control of the pointer after mouse inactivity and yields control when the user returns.

## Language

**Genuine mouse activity**:
Pointer movement, scrolling, or a stationary mouse click produced by a person's mouse or trackpad, including genuine pointer movement exposed by Windows. Keyboard activity and generated pointer movement are outside this term.
_Avoid_: General user activity, idle input

**Synthetic movement**:
Pointer movement generated by Wiggler while it is active. It never counts as genuine mouse activity.
_Avoid_: User movement

**Inactivity delay**:
The configured span of time since the most recent genuine mouse activity before Wiggler may begin moving the pointer.
_Avoid_: Movement interval

**Movement profile**:
One of the four bounded pointer paths: Linear, Diagonal, Lissajous, or Brownian.
_Avoid_: Animation mode

**Resting point**:
The pointer location when a movement profile begins. A new resting point is established each time Wiggler resumes movement after genuine mouse activity.
_Avoid_: Origin

**Amplitude**:
The maximum distance, in pixels, that any movement profile may place the pointer from its resting point.
_Avoid_: Speed

**Paused**:
A user-selected state in which Wiggler remains running but does not automatically begin synthetic movement after the inactivity delay.
_Avoid_: Exited
